# 🎓 EduQuest AI - Flutter App
Welcome to the EduQuest AI Flutter App repository! This mobile application connects students and instructors to the EduQuest AI backend, delivering real-time educational content, personalized learning, and AI-driven insights.

## Features

- **Time Management:** Keep track of lessons, deadlines, and schedules easily.  
- **Attendance & Activity Tracking:** Monitor whether students are active and present.  
- **Slide Creation:** Instructors can create and share slides for lessons.  
- **Homework Correction:** Submit, review, and correct student homework efficiently.  
- **Q&A Chat:** Students can ask questions directly in the chat for fast clarification.  
- **Instructor Notifications:** Notify instructors automatically if something is done incorrectly.  
- **Student Level Tracking (RPG):** Track student progress and levels in a gamified manner.

## Getting Started

### Prerequisites

- Flutter and Dart installed on your development machine.  
- [Official Flutter installation guide](https://flutter.dev/docs/get-started/install).  

### Installation

1. Clone the repository:  
```bash
git clone https://github.com/AyaAbdElmoneim158/eduquest_ai_flutter
````

2. Navigate to the project directory:

```bash
cd eduquest_ai_flutter
```

3. Install dependencies:

```bash
flutter pub get
```

4. Generate code for Freezed & Retrofit:

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

## Dependencies

Key dependencies used in this project:

* **`flutter_bloc` / `bloc`** – State management for predictable and maintainable code.
* **`dio` / `retrofit`** – HTTP client and REST API integration with structured requests and error handling.
* **`freezed` / `freezed_annotation`** – Immutable data classes with JSON serialization.
* **`flutter_secure_storage`** – Secure local storage for sensitive data.
* **`shared_preferences`** – Lightweight local storage for caching and offline support.
* **`flutter_svg`** – Render SVG images efficiently.
* **`flex_color_scheme`** – Create flexible and responsive color themes.
* **`get_it`** – Dependency injection and service locator pattern.
* **`pretty_dio_logger`** – Logs HTTP requests for easier debugging.

> For a full list, check the `pubspec.yaml` file.
